# 离线二维码文件传输 V1.8.4

V1.8.4 是当前桌面发送器与 Android 接收器的正式版本。Windows 电脑通过单二维码或田字形四二维码循环发送数据，Android 手机在无网络环境下使用摄像头接收、校验、预览、保存或转发文件。

## 桌面发送器

- 单码/田字四码发送，最高60页/秒；
- 每帧100～2800字节，支持拖入文件；
- `PerMonitorV2` 原生高 DPI，Windows缩放可保持125%、150%或200%；
- 二维码按整数屏幕像素/模块绘制，四码页面保持原始模块矩阵，不做破坏性拉伸；
- 尺寸30%～150%，150%填满二维码显示区域；
- 首帧元数据保持500ms，循环元数据保持100ms；
- 自动循环补发逐轮更换白化种子；
- 支持暂停、F11全屏、指定补帧和恢复循环发送。

请关闭EXE属性中的“高 DPI 缩放替代/系统（增强）”，让程序直接使用屏幕物理像素。

## Android 接收器

- CameraX直接读取 `YUV_420_888` 的Y Plane；
- 原生ZXing-C++解码，单码与四个独立ROI并行解码；
- 自动选择后置主摄并允许手动切换摄像头；
- 显示接收进度、有效帧、重复帧、CRC错误、速度和传输计时；
- 最后5%显示缺失帧编号；
- SHA-256通过后才允许保存；
- 支持文字、图片和视频即时预览，以及转发并删除；
- 开发者模式提供耗时分布、ZXing失败分类、图像质量、失败画面和Camera2实际曝光诊断。

## 完整性与兼容性

- QTX1 V1单二维码发送器；
- QTX1 V2单二维码和田字四二维码发送器；
- Base45、CRC32、Payload白化、帧序号和整文件SHA-256；
- Android最低版本：Android 7.0（API 24）。

## 构建

```powershell
.\build-android-v1.8.4.ps1
.\build-v1.8.4.ps1
```

Android构建需要JDK 17、Android SDK 36和独立签名配置。公开GitHub源码不包含签名密钥和本地Android工具链。

      扫不到或速度很慢？
      
    
        
  • 让完整二维码和四周白边都进入取景框。
    • 
        
  • 2800 字节接近 L 级容量上限并保留少量余量，二维码仍然非常密集；建议 3～4 FPS / 二维码 100%，识别困难时降低每帧字节数。

  • 避免屏幕反光，保持手机稳定，等待自动对焦完成。
    • 
        
  • 相机/相册系统权限不等于网页摄像头权限；`file://` 或 `content://` 本地文件在很多手机浏览器中会被直接禁止。
    • 
        
  • 若页面提示“摄像头 API 不可用”，需要通过 HTTPS 安装为 PWA，或使用 Android 安装版。
